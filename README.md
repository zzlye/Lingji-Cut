# 灵剪工坊

## 简介
灵剪工坊是一款面向视频搬运、整理、翻译、配音和二次剪辑的桌面软件。它可以从视频链接开始，自动完成下载、字幕识别、字幕翻译、字幕校对、配音、合成和最终导出，也可以只做其中某一步。

当前版本：0.1

## 功能介绍
- 视频链接解析、下载和素材入库。
- 一键完成下载、字幕、翻译、配音和合成导出。
- 本地字幕识别，优先使用显卡，没有显卡时自动回退到处理器。
- 字幕调整页支持从任务队列或历史记录选择视频，手动校对后重新合并导出。
- 支持英文原文和中文译文对照，字幕样式可单独设置。
- 支持文本接口配置，可用于字幕翻译、润色和补漏。
- 支持配音接口配置，可试听音色、保存配置并参与一键流程。
- 支持任务队列、历史记录、素材库播放、删除记录和一键清空。
- 支持最终导出设置，可调整分辨率、码率和格式。
- 支持手动下载封面，方便素材整理。

## Windows 本地使用
1. 打开 GitHub Releases，下载 `LingjianWorkshop-0.1.0-Setup.exe`。
2. 双击安装包，按提示安装。
3. 打开“灵剪工坊”。
4. 第一次使用先进入“设置”，确认文件保存位置。
5. 如需字幕翻译，进入“文本 API”保存 NewAPI、Gemini 或其他兼容接口。
6. 如需配音，进入“配音配置”保存配音接口和音色。
7. 回到“工作台”，粘贴视频链接，点击“解析”或“一键完成”。
8. 完成后在“素材库”播放成品，或在“字幕调整”里校对字幕并重新合并导出。

Windows 安装包会尽量自带运行所需内容。如果安全软件提示拦截本地服务，请允许本软件访问本机端口 `8765`。

## macOS 本地使用
macOS 当前推荐从源码运行：

1. 安装 Node.js。
2. 安装 Python 3.12 或更新版本。
3. 安装 ffmpeg 和 yt-dlp，并确认它们可以在终端里直接运行。
4. 在项目目录安装前端依赖：

```bash
npm install
```

5. 安装后端依赖：

```bash
python3 -m pip install -r backend/requirements.txt
```

6. 启动桌面软件：

```bash
npm run dev
```

如需打包 macOS 安装包，在 macOS 电脑上执行：

```bash
npm run build:mac
```

打包产物会生成在 `release` 文件夹。

## 服务器部署
服务器部署适合把处理服务放在一台机器上，再用浏览器访问网页界面。建议只在自己的内网、测试机或受控服务器上使用。

### 1. 准备服务器
服务器需要安装：

- Node.js
- Python 3.12 或更新版本
- ffmpeg
- yt-dlp

### 2. 安装依赖
进入项目目录后执行：

```bash
npm install
python -m pip install -r backend/requirements.txt
```

如果服务器使用的是 `python3`，把上面的 `python` 换成 `python3`。

### 3. 启动处理服务
Linux 或 macOS：

```bash
export LINGJIAN_HOST=0.0.0.0
export LINGJIAN_PORT=8765
python3 backend/run.py
```

Windows 服务器：

```powershell
$env:LINGJIAN_HOST="0.0.0.0"
$env:LINGJIAN_PORT="8765"
python backend/run.py
```

### 4. 构建网页界面
把 `服务器地址` 换成你自己的域名或 IP：

Linux 或 macOS：

```bash
export VITE_API_BASE_URL=http://服务器地址:8765
npm run build
```

Windows：

```powershell
$env:VITE_API_BASE_URL="http://服务器地址:8765"
npm run build
```

构建完成后，把 `out/renderer` 目录交给网页服务访问即可。

### 5. 访问软件
浏览器打开你部署的网页地址。首次使用建议先进入设置页，保存文件位置、文本接口和配音接口。

## 常用设置
- 文本 API：用于字幕翻译、润色、补漏和术语控制。
- 配音配置：用于试听音色、保存配音渠道和一键流程配音。
- 字幕设置：用于设置单行或双行字幕、颜色、字号、位置和样式。
- 导出设置：用于控制最终合成视频的分辨率、码率和格式。
- 文件位置：用于设置下载、处理、导出和数据保存目录。

## 如何使用
1. 在“工作台”粘贴视频链接。
2. 点击“解析”检查标题、封面和视频信息。
3. 按需要调整“一键完成”策略。
4. 点击“一键完成”，等待任务队列跑完。
5. 如果字幕不准，进入“字幕调整”，从任务队列或历史记录选择对应任务。
6. 在字幕列表里逐条修改英文原文和中文译文。
7. 保存字幕后点击“重新合并导出”。
8. 到“素材库”播放成品，确认无误后使用导出文件。

## 常见问题
### 打开后提示本地处理服务启动失败
检查端口 `8765` 是否被占用，或检查 Python 依赖是否安装完整。Windows 安装包用户可先关闭安全软件拦截后重试。

### 字幕翻译没有生效
先进入“文本 API”保存配置，并点击测试连接。使用 NewAPI 时，Base URL 通常填写到 `/v1`。

### 配音没有声音
进入“配音配置”，确认 Base URL、API Key、模型和音色都已保存，再点击试听。

### 导出文件太大
进入“导出设置”，降低码率或分辨率后重新合并导出。

### macOS 打包失败
请确认是在 macOS 电脑上打包，并且已经安装 Python、ffmpeg、yt-dlp 和项目依赖。
